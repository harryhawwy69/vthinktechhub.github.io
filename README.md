# VThink Tech Hub

The website of **VThink Tech Hub**, the Startup & Innovation Hub of Vikas College of Engineering and Technology, Nunna.

**Live site:** https://vthinktechhub.github.io

It showcases the hub's student startups (Cohort 1 · 2026), the four-stage journey from idea to revenue, ways to mentor our founders, and the team behind the hub.

## Your first open-source contribution starts here

This repo is built to be the **first open-source project Vikas students contribute to**. You don't need to be an expert. If you can edit HTML or CSS, you can help.

1. Pick an issue labelled [`good first issue`](https://github.com/vthinktechhub/vthinktechhub.github.io/labels/good%20first%20issue)
2. Comment "I'd like to work on this" so nobody else picks it up
3. Follow [CONTRIBUTING.md](CONTRIBUTING.md) to fork, edit, and open a pull request

## Project structure

```
index.html        the page (all sections: about, journey, cohort, mentors, team, contact)
css/style.css     all styles
js/main.js        startup filter + photo fallback
assets/img/       startup logos and people photos
```

No build step and no frameworks. Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

then visit http://localhost:8000.
